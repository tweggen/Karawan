- ✅ **Dead code: GroupDetector removed; L-system configs are live, the editor's other format is not (KAR-430, 2026-10-20)**: `GroupDetector` (Bron-Kerbosch cliques, replaced by `CommunityDetector` in TALE-SOCIAL Phase E) had no caller left, not even a test; deleted, and its still-used result types `DetectedGroup` / `GroupDetectionResult` moved to `GroupDetectionResult.cs`. The ticket's premise for the L-system configs was wrong: `nogame.lsystems.json`'s parametric `house1` carries an embedded `config`, and `HouseInstanceGenerator` reads it. What was dead is Aihao's object format `{definitions, configs}`, which the game never reads, and LSYSTEM.md documented that format. Found on the way: the editor never listed the embedded config (so it could not be edited), "+ Config" made a free-standing config the save then dropped, and `LSystemConfigViewModel` lacked `upperSegmentProbability` / `singleBlockProbability`, so a save from Aihao silently removed them (the game's defaults happen to equal today's values). Now the editor reads and writes only the array format, lists each parametric definition's config under it, adds a config to the selected definition, removes it with its definition, and round-trips all fields — checked by loading the shipped file into the view model and writing it back (master: config differs; now equal). No Aihao test project exists.
